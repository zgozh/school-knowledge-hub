# ADR-006: 检索链路参数与时效感知

- 日期：2026-08-18
- 状态：已接受

## 背景
校务通知类信息时效敏感（新通知优先、过期信息会误导办事）。需沿用 DocMind 实证检索参数，并新增时效感知。

## 决策
- 混合检索：dense COSINE 0.8 + sparse IP 0.2，norm_score 归一化（沿用 DocMind 实证参数）。
- 召回 top10 → bge-reranker-large 精排 → 断崖截断（动态 top-k）。
- 时间衰减：按发布天数指数衰减，半衰期 30 天，系数配置化。
- 过期降权：过期文档衰减加倍并在答案中标注"可能已过期"。
- 元数据过滤：分类/专题域过滤在检索时应用。

## 备选
- 固定 top-k：不如断崖截断贴合实际相关性分布。
- 无时间衰减：通知场景会让旧公告排前——否决。

## 后果
- 正面：直接复用 DocMind 实证参数，降低调参成本；时间衰减呼应主题"可信"。
- 硬约束关联：答案可信（来源+时效双保险）。
- 重新评估触发：若评测显示半衰期 30 天对新闻类（非通知类）过度降权，按分类差异化配置衰减系数。
