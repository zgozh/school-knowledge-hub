# ADR-010: 数据策略（真实采集 + AI 生成模拟数据脚本）

- 日期：2026-08-18
- 状态：已接受

## 背景
硬约束"零内网依赖"：演示必须不依赖学校内部系统即可完整运行。同时"自动采集"主题要求有真实采集能力证明。

## 决策
- 真实采集：广州大学官网（www.gzhu.edu.cn 通知公告等栏目）与新闻网（news.gzhu.edu.cn）公开页面，采集管道真实运行。
- 模拟数据：AI 编写数据生成脚本，自动生成逼真的通知/制度/办事指南（覆盖专题域：新生入学/港澳生服务/教务学籍等），演示可复现。
- 演示环境 = 真实采集数据 + 模拟数据共同入库。

## 备选
- 纯真实数据：受公开信息量与栏目覆盖限制，不足以覆盖演示场景。
- 纯模拟数据：无法证明"自动采集"能力——否决。

## 后果
- 正面：真实采集证明能力，模拟数据覆盖场景，演示可信且可复现。
- 硬约束关联：零内网依赖、单机可复现。
- 重新评估触发：无需评估。

## 人工资源依赖
无（脚本由 AI 生成）。
