# ADR-005: 嵌入与重排模型本地服务（FlagEmbedding FastAPI）

- 日期：2026-08-18
- 状态：已接受

## 背景
需要 embedding（dense+sparse 双输出）与 reranker 两个本地推理能力。用户已有本地权重：BGE-M3 与 bge-reranker-large（注意：**不是** bge-reranker-v2-m3）。

## 决策
FlagEmbedding 自建独立 FastAPI 服务（`model_server`），一个进程暴露两个接口：`POST /embed`（BGE-M3 dense+sparse 双输出）、`POST /rerank`（bge-reranker-large）。权重挂载本地路径，不依赖运行时下载。

## 备选
- Ollama：官方支持 bge-m3 但**不支持 reranker**、只出 dense（sparse 不开放）——否决。
- TEI：高性能但镜像/模型下载依赖网络（翻墙/镜像站），部署重。
- 云端 embedding API：数据出域、有费用——否决。

## 后果
- 正面：满足 hybrid 双输出 + reranker 两个诉求；CPU 即可跑（BGE-M3 约 2GB、reranker-large 约 1.3GB）；用户有 FlagEmbedding 部署经验。
- 硬约束关联：零内网依赖（本地推理）；单机可复现（容器挂载权重）。
- 重新评估触发：若 CPU 推理延迟影响演示（问答超时），考虑 GPU 或换 TEI。
