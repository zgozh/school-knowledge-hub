# ADR-009: 前端技术栈（Vue 3 + Element Plus）

- 日期：2026-08-18
- 状态：已接受

## 背景
需要管理后台（采集源/任务监控/知识库管理/资产全景）+ 聊天问答界面（SSE 流式 markdown）。演示视频评审，UI 质感重要。单人开发。

## 决策
Vue 3 + Vite + Element Plus（管理端）+ markstream-vue（聊天流式 markdown 渲染）。SSE 后端用 sse-starlette（FastAPI EventSourceResponse）。单 SPA 双布局：`/` 问答端、`/admin` 管理端。

## 备选
- Naive UI / Ant Design Vue：可用，但 Element Plus 中文生态与模板最丰富。
- React + Ant Design：技术栈不一致（后端 Python 全栈），不推荐混合。
- 手写 markdown 流式渲染：markstream-vue 已有现成方案，不自研。

## 后果
- 正面：组件全、模板多、中文资料丰富；kimi-k3 前端模型对 Vue 生态熟悉。
- 硬约束关联：演示视频质感（管理端图表 + 聊天流式效果）。
- 重新评估触发：若 markstream-vue 维护不佳或渲染 bug，换 vue-markdown 类库。

## 人工资源依赖
npm 依赖一次性安装（网络）。
