# ADR-004: 对象存储选型 MinIO（复用已有服务）

- 日期：2026-08-18
- 状态：已接受

## 背景
需要存储采集的原始 HTML 快照与附件，支撑"答案→源头"溯源演示（来源引用卡片可回溯原文）。用户已有 MinIO 服务。

## 决策
使用 MinIO：原始 HTML 快照与附件入库 MinIO；元数据中记录快照对象键。

## 备选
- 本地文件系统目录：零依赖，但无对象级寻址，"中台"资产化叙事弱。
- 其他对象存储（OSS/S3 云）：需外部账号与费用——否决。

## 后果
- 正面：支撑知识溯源演示；服务化存储贴合"中台"。
- 降级：MinIO 不可用时跳过快照存储（元数据照常），标记"快照缺失"（spec 第 8 节）。
- 重新评估触发：无需评估（已有服务）。

## 人工资源依赖
MinIO 镜像提前 `docker pull`；开发期可用 WSL 现有服务；需确认 bucket 初始化脚本。
