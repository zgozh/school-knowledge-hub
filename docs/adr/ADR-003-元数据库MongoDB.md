# ADR-003: 元数据库选型 MongoDB（复用已有服务）

- 日期：2026-08-18
- 状态：已接受

## 背景
需要存储文档元数据（标题/日期/栏目/分类/专题域/时效状态）、采集任务状态与日志、问答日志、统计聚合。用户已有 MongoDB 服务。

## 决策
使用 MongoDB：文档元数据/任务状态/问答日志/统计统一入 MongoDB（替代 SQLite 方案）。

## 备选
- SQLite：零依赖，但半结构化文档与嵌套查询表达弱，"中台"叙事弱。
- PostgreSQL：需新装，且对半结构化文档不如 Mongo 自然。

## 后果
- 正面：半结构化文档天然合适；复用 DocMind 会话存储经验；贴近生产级"中台"叙事。
- 硬约束关联：单机 compose 可复现（编入项目 compose）。
- 重新评估触发：无需评估（已有服务，成本为零）。

## 人工资源依赖
MongoDB 镜像提前 `docker pull`；开发期可用 WSL 现有服务。
